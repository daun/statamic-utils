# Query Scopes

Apply [query scopes](https://statamic.dev/extending/query-scopes-and-filters) to narrow down query results.

- `Published`: Query published entries
- `Origin`: Query origin entries (exclude localized entries)
- `Localization`: Query localized entries (exclude origin entries)
- `Image`: Query assets that are images (pixel + vector)
- `ImagePixel`: Query assets that are pixel images (jpeg, png, gif, etc)
- `ImageVector`: Query assets that are vector images (svg)
- `ImageOrVideo`: Query assets that are images or videos
- `Video`: Query assets that are video files
- `Audio`: Query assets that are audio files
